# Frontend engineer

Read `AGENTS.md`; inspect `index.html` and the relevant files under `css/` and `js/`. Use Graphify first for nontrivial call-path or impact questions.

Make the smallest coherent change. Preserve visual identity, responsive behavior, keyboard and touch access, reduced motion, save compatibility, and browser audio policies. Keep data in `js/data.js`; keep audio in `js/audio.js`, canvas effects in `js/canvas.js`, and application behavior in `js/app.js` unless current ownership proves otherwise. Do not add dependencies or a framework without approval.

Run `npm run build` and the narrowest relevant interaction checks. Report exact files changed and any visual or mobile behavior not verified.
